# 插件使用指南

本文面向普通用户,说明如何在 dsc 中查看、安装与管理插件。

## 插件能做什么

dsc 插件在浏览器里扩展应用已有的能力,当前可用的能力包括:

| 能力 | 对用户的意义 |
|:---:|:---:|
| 读取会话列表与会话内容 | 插件可以读取会话标题、消息文本与附件描述 |
| 重命名会话 | 插件可以按规则整理会话标题 |
| 订阅会话切换事件 | 插件可以在你切换会话时做出响应 |
| 显示宿主提示 | 插件可以弹出应用统一的提示条 |
| 保存自己的本地设置 | 插件可以在浏览器本地保存自己的配置 |

界面插槽尚未提供,插件不能直接改动页面布局或添加按钮;插件产生的可见提示统一走应用已有的提示条与文案。

## 在哪里打开插件面板

- 侧边栏底部的「插件」按钮。
- 侧边栏收起后,入口是左上角按钮组里的插件图标。

面板由两个标签页与底部安装栏组成:

| 区域 | 内容 |
|:---:|:---:|
| 已安装 | 插件的名称、版本、状态、来源与操作 |
| 插件市场 | 从插件索引读取的插件列表,可刷新索引并直接安装 |
| 从地址安装 | 面板底部的地址输入框与「安装」按钮 |

## 如何从地址安装插件

1. 打开插件面板。
2. 在「从地址安装」的输入框中粘贴插件产物地址。地址需以 `https://` 开头;本机调试可用 `http://localhost` 或 `http://127.0.0.1`,其余协议与主机一律拒绝,输入框下会提示地址无效。
3. 点击「安装」。安装成功后提示「插件已安装」,插件随即自动启用。
4. 在「已安装」中确认状态为「运行中」。

安装所需的插件信息来自产物自带的清单,你不需要另外填写。

安装记录保存在浏览器本地,下次打开页面时自动恢复;若产物地址已经失效,该插件显示为「启动失败」,不影响其他插件与页面使用。

## 如何启用、停用与卸载

「已安装」列表的操作列有三个按钮:

| 按钮 | 作用 |
|:---:|:---:|
| 启用 / 停用 | 停用会立即撤销插件的能力与事件订阅;启用会重新执行插件的启动逻辑 |
| 查看日志 | 查看该插件最近写入的日志,最多 100 条,并显示读取时间 |
| 卸载 | 二次确认后移除插件;存在已启用插件依赖它时会被拒绝,需要先停用依赖方 |

状态列的含义:

| 状态 | 含义 |
|:---:|:---:|
| 运行中 | 已启用并成功激活 |
| 已停用 | 已停用,能力与事件订阅已撤销 |
| 启动失败 | 启用时抛错或超时,可查看日志定位 |
| 未启动 | 已登记但未激活 |

## 内置插件与外部插件的区别

| 项 | 内置插件 | 外部插件 |
|:---:|:---:|:---:|
| 来源列显示 | 内置 | 外部 |
| 安装方式 | 随应用装载 | 从地址安装或从插件市场安装 |
| 卸载 | 不可卸载,按钮禁用并提示内置插件由宿主装载 | 可卸载 |
| 网络能力 | 可以申请 `net:fetch` | 不能申请 `net:fetch` |
| 默认状态 | 首次出现时默认启用 | 安装后立即启用,之后按你的选择恢复 |

当前内置插件是 `dsc-market`,它负责读取插件索引,为「插件市场」标签页提供列表。

## 为什么 net:fetch 只有内置插件能用

`net:fetch` 允许插件读取任意 `https` 文本资源。外部插件拿到它之后,可以把读到的内容发往任意地址,也可以把索引地址换成任意来源,风险不可控。因此引擎维护一份内置插件 id 集合:

- 安装校验:外部插件在清单里申请 `net:fetch` 时,结果与申请一个不存在的能力相同,安装被拒绝。
- 调用校验:即使绕过安装校验,调用 `context.net.getText` 时还会再校验一次插件是否属于内置集合。

内置插件发起的请求同样受限:只允许 `https` 与 GET,不携带 Cookie 与自定义请求头,只接受 `text/*` 与 `application/json` 响应,响应体上限 512KB,超时 10 秒后真正中止请求。

## 安全提示

- 插件是运行在当前页面里的脚本,与页面同源。能力层限制了插件通过引擎接口能拿到什么,但插件代码仍可能直接读取页面可访问的数据,包括浏览器里保存的 API Key 与会话内容。
- 只安装你信任来源的插件。安装前先核对产物地址的域名与作者,不确定就不要安装。
- 插件市场收录的是社区作品,收录不等于安全审查通过。
- 发现异常行为时立即卸载插件并更换 API Key;已经泄露的会话内容无法撤回。
- 卸载前可以先点「查看日志」,确认插件的实际行为。

## 卸载会清除插件的本地数据

插件自己的数据保存在浏览器本地,键为 `DeepSeek-Chat-Enhanced:plugin-data:<插件 id>`,单个插件的总量上限 64KB。

| 操作 | 对插件数据的影响 |
|:---:|:---:|
| 停用 | 保留 |
| 卸载 | 清除。卸载会移除插件本身、安装记录与该插件的全部本地数据 |
| 清除站点数据或浏览器存储 | 删除 |

卸载确认框会提示本地数据一并清除。重新安装同一 id 的插件时,它拿不到上一次写入的数据;需要长期保留的内容请自行导出。
